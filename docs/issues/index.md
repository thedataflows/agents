# Issues

Issues track units of work: features, bugs, tasks, and chores. They
describe *what* needs to happen; ADRs describe *why* things are the way
they are. When an issue and an ADR disagree, the ADR wins.

Conventions: [issues-conventions.md](issues-conventions.md). Template:
[TEMPLATE.md](TEMPLATE.md). Plans that implement these issues follow
[../plans/plans-conventions.md](../plans/plans-conventions.md).
